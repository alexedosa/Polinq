Polinq Design Language v1
Philosophy

Polinq should feel:

Premium
Calm
Intentional
Spacious
Modern
Confident

The interface should feel like a high-end operating system, not a social media app.

Design with restraint. Remove unnecessary decoration before adding more.

Color Palette
Primary
Black – Primary text, navigation, emphasis.
White – Primary canvas and surfaces.
Dark Orange – Brand accent. Reserved for meaningful actions and important highlights.
Supporting
Neutral greys for:
borders
dividers
muted text
secondary surfaces
disabled states

Orange should never dominate the interface.

Glassmorphism

Glass effects are not part of the main design language.

Use them sparingly.

Approved places include:

Floating utility buttons
Bottom utility icons (logout/settings/help)
Small profile widgets
Floating quick actions
Selected premium moments

Never apply glassmorphism to:

Main content cards
Feed cards
Forms
Navigation panels
Entire layouts

Glass is an accent, not a theme.

Cards

Cards should feel:

Soft
Minimal
Spacious

Characteristics:

Large corner radius
Very subtle borders
Minimal shadows
Generous internal spacing

Cards should appear self-contained without looking heavy.

Layout

Application structure:

Top Navigation

↓

Left Navigation

↓

Large Dynamic Workspace

The workspace is the hero.

Avoid clutter.

Prefer fewer, larger modules over many small widgets.

Spacing

Whitespace is a feature.

Never fill empty space just because it exists.

Every screen should feel breathable.

Typography

Use Plus Jakarta Sans.

Hierarchy should rely on:

Size
Weight
Spacing

Not excessive colors.

Motion

Motion should be:

Smooth
Slow
Purposeful

Avoid flashy animations.

Use motion to communicate state changes.

Borders

Prefer:

subtle grey borders

instead of

heavy shadows

or

thick outlines
Icons

Icons should be:

clean
minimal
outlined where appropriate

Orange icon fills should be used only for active or important actions.

Navigation

Left navigation should feel calm.

Active item:

orange indicator
subtle background
stronger text

Not a giant colored pill.

Pulse Philosophy

The dashboard should feel like:

A live operating system for your community.

Not:

A traditional analytics dashboard.

Every module should answer something meaningful about the user's nearby world.

Premium Principles
Remove before adding.
Fewer colors.
Larger spacing.
Bigger typography.
Consistent radii.
Consistent grid.
Consistent motion.
Never decorate for decoration's sake.
